# Soulmate

一个住在你电脑里的 AI 陪伴应用。不是聊天机器人工具，是一个**有记忆、有心情、会主动开口**的她。

她记得你说过的话（本地向量记忆 + 长期记忆管线），有今天想不想说话的兴致（不会永远热情，也不会永远敷衍），会自己决定什么时候找你——以及什么时候不打扰。她说话像发微信：流式上屏、分条短句、偶尔"打了一半删掉重打"。

> 这是个人项目，代码从自己的真实使用里长出来，注释里写满了每个设计决策的"为什么"。

## 功能

- **聊天**：流式输出、微信式分条气泡、右键重新生成她的回复、右键复制
- **记忆**：本地 faiss 向量检索 + 摘要管线 + 关系/人格状态随对话演进
- **主动消息**：守门人机制决定她什么时候开口、说什么、每天最多几条
- **多服务商**：任何 OpenAI 兼容接口（DeepSeek / Kimi / 智谱 / 千问 / OpenRouter / 本地 Ollama），三个角色（理解/回看/说话）可分别指定模型
- **中英双语**：首次启动选语言，设置里随时切换
- **数据安全**：JSON 原子写入、每日自动备份（保留 7 份）、API Key 用 Windows DPAPI 加密
- **桌面体验**：系统托盘、主动消息系统通知、聊天记录搜索（Ctrl+F）与导出、开机自启

## 快速开始

需要 Python 3.12+ 和 Windows（DPAPI 加密与自启用到 Windows；macOS/Linux 未测试）。

```bash
git clone https://github.com/<你的用户名>/soulmate.git
cd soulmate
pip install -r requirements.txt
python main.py
```

首次启动会依次出现：语言选择 → 设置向导（选服务商、填 API Key、给她起名字）→ 主界面。

Embedding 模型（BAAI/bge-small-zh-v1.5，93MB）首次使用记忆功能时自动下载，也可用 `download_model.py` 预下载。

## 数据在哪

所有数据在程序旁边的 `SoulmateData/`（便携模式），没有这个目录时用 `%APPDATA%/Soulmate/`。聊天记录、记忆、向量库、配置全在里面——**备份这个目录 = 备份她**。

## 项目结构

```
main.py              桌面端入口
web_server.py        网页端服务（可选，浏览器/手机访问）
core/                大脑：人格、情绪、记忆检索、主动消息守门人
memory/              记忆：向量库、管线、关系、用户画像
llm/                 模型接入：多服务商、重试、降级
prompt/              提示词拼装
ui/                  PySide6 界面
web/                 网页端静态页面
```

## 隐私

- 所有对话和记忆只存在你自己的电脑上
- API Key 用 Windows DPAPI 按当前用户加密，拷到别的机器解不开
- 主动联网的只有你配置的模型服务商和天气查询
